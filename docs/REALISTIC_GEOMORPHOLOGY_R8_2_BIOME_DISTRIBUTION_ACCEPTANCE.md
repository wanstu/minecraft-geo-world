日期 2026-11-18。新世界规则为 `geoworld-rules-v1.1.27`。对照规则为已提交的 Slice E `geoworld-rules-v1.1.26`，提交 `afd7499`。

## 群系实现

森林竞争条件收紧到较湿润的环境，扩大草原、灌丛与稀树草原的自然过渡带。珊瑚使用持久化的 SST，混合海岸格只对海洋节点插值。具备海洋背景的暖浅海在 SST 至少 24°C、归一化水深 0.008–0.055 且离开正式河口及强河流影响后，可根据连贯的海域分布生成 `minecraft:warm_ocean`。局地海洋占比和强季风降水用于近岸淡水与浑浊影响的近似。模型目前以平滑空间变化表达底质及波浪暴露度，珊瑚装饰仍由 Minecraft 原版生成。暖水浅海的其余部分使用 `minecraft:lukewarm_ocean`。

新规则取消 `warm_ocean` 的通用群系保底圆。群系覆盖和地表材料检验从自然礁区取得样本。固定种子的 v1.1.26 与 v1.1.27 具有相同的地形、河湖模型、气候基线和 18 个特殊地貌。953 条河段包含 88 个 OceanMouth。存档继续按自身规则版本加载。v1.1.27 对齐 Java 与 Go 的河岸保护水位，河口展宽使用正式河道宽度计算水深。
