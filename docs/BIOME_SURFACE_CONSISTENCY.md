# GeoWorld 全主世界群系 × 地表材质一致性（2026-10-11）

## 问题与结论

用户实机观察到：`minecraft:desert` 地面出现成片泥土，`minecraft:badlands` 没有红沙、陶瓦，而 GeoWorld 世界预览生态模型仍显示温带荒漠、冲积土或灌丛土。

调查确认根因是 **两条不一致的数据源**：

1. `Minecraft26_3BiomeRealizer.biomeId(...)` 从 GeoWorld 生态/气候/形态选择最终 Minecraft 群系，另外叠加 `Minecraft26_3BiomeCoverage` 稀有群系保底。
2. `GeoWorldChunkGenerator.blockAt` 原本使用 `RuntimeSample.surfaceProfile()` 独立决定实际方块，从未询问最终 Minecraft 群系。荒漠里的 `Alluvial Silt -> grass_block` 和 `Shrub Soil -> coarse_dirt` 正是可复现的例子。

同时发现两项潜在错误：
- 上一轮 56 群系保底允许候选中心冲突，某些种子上 `river` 被 `frozen_river` 的覆盖区抢占。原 `56/56` 只统计“某处出现”，不能保证每一处保底中心。
- 原候选评分让 `windswept_hills` / `windswept_gravelly_hills` 越过真正的沙漠/恶地，在干旱山地出现生态标签不一致。过渡边界由 `erodedBoundaryBiome` 正常混合的部分保留。

## 修复架构

新增 `GeoWorldSurfaceMaterials`：将 Minecraft **最终群系**映射到覆盖层与浅层材料。GeoWorld 模型仍负责高度、坡度、水文及底层生态，未反向修改科学模型。

`GeoWorldChunkGenerator` 每列的表面 `groundBoundary-1` 处调用 `Minecraft26_3BiomeRealizer.biomeId`，在 `buildTerrain` 和 `getBaseColumn` 中共享同一块材质规则：

- 沙漠 -> 表面沙子、浅层砂岩；绝不因 GeoWorld 中间土壤为灌丛土、冲积土而铺泥地。
- 恶地 -> 平缓表面红沙，强侵蚀/岩质地面陶瓦，约 50 格以内维持 Y 连续的分层陶瓦（红、橙、黄、白、棕及常规等）；地表不会大量出现泥土草块。
- 雪地、雪山、冰刺、积雪针叶林 -> 雪块；部分高山根据岩面选择石头。
- 海滩 -> 沙子 / 积雪海滩 -> 雪 / 石岸 -> 石。
- 深浅海 -> 遵从地理海床材料；冰冻海水规则照旧。
- 蘑菇岛 -> 菌丝；苍白之园 -> 苍白苔藓块。
- 沼泽 -> 湿地泥 / 草地；红树林沼泽 -> 泥。
- 原始针叶林 -> 灰化土；风袭沙砾丘陵 -> 沙砾；普通草地、森林、雨林、热带草原 -> 草方块。
- 洞穴 4 类仍使用地下层规则，不硬把洞穴群系材料铺在地表。
- **水文优先级更高**：已通过岸线/湿地修复决策的 `surfaceOverride` / `underOverride` 保留，不为了群系好看破坏连续水源或浅滩。
- 只作用于 GeoWorld 使用的生成器，不修改其他世界/其他 MOD 的材质。

**保底群系修复**：在密集水文位置增加河流专属候选扫描；相邻保底中心必须至少间隔 256 方块，实际覆盖点按最近中心决定，避免不同群系抢同一处。保底只影响群系网格及材质，不修改地形、水面归属。

**生态候选修复**：如果模型明确标记为荒漠，禁用两个无生态限制的温带风袭丘陵候选；荒漠内部自然选择沙漠/恶地，原生生态区交界的正常过渡仍保留。

## 永久审计

`./gradlew.bat verifyGeoWorldSurfaceBiomes` 被纳入 NeoForge `check`：

- 56 种主世界群系必须全部有地表材质分类，4 种洞穴群系单独统计。
- 在 52 个地表群系保底区域，对每处 3×3 = 9 列验证真实 `biomeId`、表面材质、浅层材料（共 468 列，936 材料检查）。
- 专项断言包括沙漠×灌丛土、沙漠×冲积土、恶地×灌丛土、恶地陶瓦分层、蘑菇岛、苍白之园、雪地、沼泽、针叶林、海岸及雪山。
- 验证沿水文岸线的优先材质不会被强制群系覆盖。
- 扫描独立生态候选网格，荒漠**内部**不得出现错误的温带草原/风袭丘陵，真实生态交界保留正常融合。
- 可以使用 `-PgeoWorldSurfaceSeed=123456` 指定种子，在图片所示 `-563659577384754347` 上也有回归输出。
- 保留原有 `auditGeoWorldBiomeCoverage`，其 56/56 还必须证实**实际群系存在**，不能仅靠登记。

## 注意事项

这次修改的是 Minecraft Java 地表落块和群系筛选，不改变 Go 地形/水文模型。已生成区块不自动重铺；请用新世界重新验证。Engine cache v15 的原始地理数据无需因此重建。紫水晶/矿脉及原版结构仍应由原有回归守护。

地图上的群系出现，不等于原版全部对应独特地物、洞穴空间及结构都达到预期。本次只以真实群系、地表/浅层方块和地理协调性为验收对象。
