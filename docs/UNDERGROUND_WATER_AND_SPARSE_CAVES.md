# GeoWorld 地下水 / 稀疏洞穴路线图（2026-10-11）

## 用户意图
- 主世界保留复杂地表和主世界全部群系、全部矿物。
- **不希望遍地都是大型天然洞穴或地表洞口**；不会以“恢复原版所有洞穴密度”为目标。
- 将来希望能看到少量与地质环境有关的地下河、岩溶侵蚀形成的洞穴，地下水与地表河流联系起来。
- 本阶段先优化区块生成性能、维护现有低洞穴密度，不启用新洞穴/地下河实现。

## 拟议顺序（尚未实施）

1. **水文模型**：基于降水、地表渗入、地下岩性渗透率、地下水位，生成低分辨率地下水流场（permeability、水头梯度、补给区、汇流点），并通过 GeoWorld 世界模型持久化。
2. **地质门控**：仅在可溶岩（石灰岩/白云岩等）或岩层裂隙集中区、且有足够水量时，允许地下水侵蚀通道；坚硬岩层默认不生成大量空洞。尚无地下岩性数据时不应伪称“真实岩溶”，需先补地层模型。
3. **稀疏通道**：少量地下河流域产生连续低概率通道（通道宽度、坡度跟随水位和流量），不等同大量随机噪声洞穴；低密度、低地表开口比例为正式验收参数。
4. **出口与联通**：泉眼、地下河入河点、水体连接由同一个 WaterOwnership / receiver 机制确定。河流水源应贴合实体岩壁/河床，禁止出现无归属悬空单格水源。
5. **Voxel 整合**：先固体与洞穴 carve，再矿脉生成/露头，再地下水填充，最终合并岸线与流体 tick 审计；洞穴不得打断既有河床、湖底、海床，不得用流动水一次性填满洞窟。
6. **验收**：洞穴面积及地表洞口占比、每 km² 可通行洞道数、地下河段连通率、矿脉与洞穴壁交叉概率、fluid tick 密度、地表水体的 ownership 与无泄露，作为长期回归。

**不做**：短期内重启大量 vanilla random Carver、以纯 3D 噪声挖遍全世界、用反复流体更新代替静态水文结果、承诺每种洞穴群系一定有对应体量的空洞。

## 生成性能（本期）
NeoForge 客户端有明显区块填充延迟。先通过模型侧与完整区块侧 profiler 区分：加载模型、shoreline plan、biome resolver、voxel 写入、矿脉、装饰、客户端渲染。优化必须输出修改前后可复测数字，保留真实 Seed 123456 / -563659577384754347 的群系及水体回归。
