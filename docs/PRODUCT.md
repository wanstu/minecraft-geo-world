# GeoWorld 产品边界

## 1. 核心目标

生成一个“可以解释为什么会长成这样”的 Minecraft 世界。

GeoWorld 关注长期地理形成过程，而不是短期天气模拟。

### GeoWorld 负责

- 板块划分与运动趋势
- 大陆 / 海洋分布
- 山脉、高原、裂谷、海沟、岛弧
- 基础侵蚀和沉积结果
- 大尺度盛行风
- 洋流
- 季风对长期降水和湿度的影响
- 年均温、降水、干湿度、季节性等长期气候参数
- 水系和流域
- 生态区
- Minecraft Biome / Terrain 映射

### GeoWorld 暂不负责

- 动态四季
- 每日天气预报
- 每 Tick 全球大气模拟
- 动态更换 Biome
- 真实流体海浪
- 球形 Minecraft 几何

这些能力未来可以由独立 Mod 通过 GeoWorld API 读取长期气候数据后实现。

## 2. 世界拓扑

### V1：无限 MC 平面 + 有限地理世界

Minecraft 本身继续使用普通无限平面坐标。

中央区域为 GeoWorld 主模拟区，外围为过渡区，再向外进入无限特殊海洋。

```text
                 Infinite Frozen Ocean
                         ↑

             北极 / 季节性海冰过渡带

 Infinite      ┌──────────────────┐      Infinite
 Storm Ocean ← │  GeoWorld Region │ → Storm Ocean
               │  大陆 / 正常海洋 │
               └──────────────────┘

             南极 / 季节性海冰过渡带

                         ↓
                 Infinite Frozen Ocean
```

### 设计意义

- 不需要处理球面首尾拼接。
- 板块模拟规模有明确上限。
- 气候有确定纬度方向。
- MC 玩家仍可继续向任意坐标探索。
- 主模拟区之外的生成成本非常低。

## 3. 气候与季风

季风属于“气候形成机制”，而不是要求游戏内实时换季。

世界生成阶段允许内部计算月份或夏/冬两个代表态，用于得到：

- 年均温
- 年降水
- 降水季节性
- 夏季 / 冬季主导风向
- 季风强度
- 干旱指数
- 雪线 / 冻土倾向

Minecraft 最终得到稳定的生态群系。

未来季节 Mod 可以读取这些数据，在运行时决定雨季、雪季、植被颜色或区域天气。

## 4. 产品形态

### GeoWorld Generator

面向地图作者、开发者和算法调试。

主要能力：

- 创建 / 保存世界模型
- Seed 与世界尺寸配置
- 模拟阶段运行
- 多图层查看
- 参数调试
- 世界统计
- 导出高度图 / 数据包 / Minecraft 世界
- 预生成指定区域

### GeoWorld Runtime

面向普通 Minecraft 玩家。

主要能力：

- 创建世界时选择 GeoWorld
- 选择世界尺寸 / 地理预设
- Seed
- 兼容的 Loader Adapter
- 按需读取或计算宏观世界模型
- 按 Chunk 生成实际方块
- 暴露长期气候查询 API

## 5. 原则

1. 地理规律优先于随机噪声。
2. 噪声只负责局部细节，不负责宏观大陆结构。
3. 大尺度数据先生成，小尺度 Chunk 后细化。
4. 核心数据不绑定某个 Mod Loader。
5. 世界结果应可解释、可检查、可复现。

## 6. 世界配置生命周期

GeoWorld 的地理生成参数属于 **World Creation Settings**，不是全局运行时设置。

### 创建新世界时

允许配置：

- Seed
- 地理区域尺寸
- 板块数量 / 活动度预设
- 海陆比例 / 大陆丰富度
- 模拟精度
- 外围风暴洋 / 冰冻洋过渡宽度
- 结构兼容策略

创建世界后，这些配置必须写入该世界自己的 GeoWorld 元数据中。

### 已有世界

已有世界只允许查看这些生成参数，不允许直接修改。

如果修改会影响新 Chunk 的生成结果，就会产生“旧区块按旧规则、新区块按新规则”的明显割裂。

因此 V1 原则是：

> **会改变地形、气候、群系、水文或世界边界语义的设置，只在创建新世界时生效。**

运行时仍可允许修改不影响世界生成结果的显示类或性能类选项，例如：

- 调试图层开关
- 日志等级
- 缓存容量
- 预加载半径
- 可视化精度

如果未来需要迁移世界参数，应使用显式的“世界升级 / 重生成工具”，不能把它伪装成普通设置修改。
