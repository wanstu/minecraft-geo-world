# GeoWorld 主世界矿物和群系覆盖（2026-10-11）

## 目标与范围

- 仅修改 GeoWorld 使用的主世界（Overworld）生成器；普通原版世界、下界、末地、其他 MOD 的矿物 Feature 不主动过滤或更改。
- 所有 Minecraft 26.3 主世界矿物类型存在，并能在实际地下岩层形成连续矿脉。
- Minecraft 26.3 `is_overworld` 标签中的 **56 种群系必须真实出现在默认 GeoWorld 世界**，不仅注册到 possible biomes。
- 地质生态优先；全局稀有种类添加稀疏、确定性保底，而不完全依赖概率。

## 矿产生成

GeoWorld 先 voxel 化地形，再对真实石层填充矿脉。按世界坐标确定性生成，矿脉跨区块边界连续，区块加载顺序不影响结果。

矿石（普通石/深板岩两种）：
- 煤矿：浅部 / 平原沉积环境更常见；深层也有少量。
- 铁矿：山区及山麓富集。
- 铜矿：山地构造活动区富集。
- 金矿：台地、峡谷和干旱环境有较高权重。
- 青金石矿：沉积环境略富集。
- 红石矿：深层更常见。
- 钻石矿：深层更常见，地表环境不主导。
- 绿宝石矿：高山及山麓富集；深层少量。

空间参数：
- 常规矿脉宽约 2~4 格、长度 13~31 格；少量大型矿脉长约 32~48 格。
- 常规候选源单元：64x64x48 Minecraft 方块。
- 每个 1024x1024 级联单元中，为 8 类矿石各保留一组普通和深板岩矿脉（置于对应适宜高度）；最后只替换 STONE / DEEPSLATE，故矿脉不会穿透海水、泥土、雪层、空气、基岩及外部结构。
- 额外按 1024x1024 单元安排地下紫水晶晶洞（含紫水晶块、紫水晶母岩、方解石、平滑玄武岩）；原版 `amethyst_geode` 继续保留。
- 原版 8 类 Overworld 矿物 `ore_*` PlacedFeature 在 GeoWorld 生成器内过滤，避免与专属矿脉逻辑重复；非矿物地质装饰 `ore_gravel`、`ore_tuff`、紫水晶晶洞、`spring_lava`、树木、其他 MOD Feature 保留。

限制：当前地质类型从现有地表 TerrainVariant/BiomeFamily 推断，尚没有持久化的地下岩性、深层地热及矿床成因模型。保底矿脉存在于不同地貌中，但常规矿脉仍有地质倾向。

## 群系保证

- 原默认种子 123456 的三维覆盖审计在 70,231 次采样中仅发现 **36/56**；当时 56/56 是 *已注册* 群系，不是 *真实生成* 群系。
- 新增 `Minecraft26_3BiomeCoverage`，按世界配置在整个有限地图中搜索气温、降水、地形、水域条件合适的位置，为每种主世界群系保留具有面积的候选区域。固定世界 Seed 与配置产生固定结果；尽量优先生态匹配，不修改既有 Terrain/Water 方块。
- 表层/水域区域不覆盖深层洞穴群系，地下洞穴群系只在对应高度带覆盖。所有群系仍使用 Minecraft 官方群系注册表及装饰系统。
- 默认 Seed 123456：80,264 次三维实际 `biomeId` 采样，结果 `observed=56 / required=56 / missing=0`，且验证所有保底群系区块的内部联系。
- 该机制确保群系 ID 真实落在区块群系网格中，**不等于**保证每种地物/独立结构、每个群系面积都和原版一致。尤其洞穴内部空间仍取决于洞穴雕刻/结构系统。

## 正式回归

- `./gradlew.bat auditGeoWorldBiomeCoverage`：默认种子全世界群系出现性。
- `./gradlew.bat auditGeoWorldBiomeCoverage -PgeoWorldBiomeSeed=-4852173505788415804`：指定种子覆盖。
- `./gradlew.bat verifyGeoWorldMinerals`：验证八类矿石普通/深板岩矿脉实际命中地下石层、地质偏好、跨区块连续性和紫水晶晶洞。
- `./gradlew.bat verifyGeoWorldDecorationPolicy`：确认目标原版矿石被过滤，但原版地质装饰、原版紫水晶及第三方矿物 Feature 仍保留。
- `./gradlew.bat build`：以上验证纳入主构建，同时运行 Shoreline/WaterOwnership 等完整回归。
- 引擎缓存前缀：`v14 -> v15`。新世界/未生成过的区块才能看到新矿脉；不要在既有区块验证新版矿物。
