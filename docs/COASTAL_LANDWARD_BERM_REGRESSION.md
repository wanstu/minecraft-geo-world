# 2026-10-11 · 干地侧海岸沙堤斜坡专项（t30 截图）

## 反馈和真实原因

用户在 t30（种子 -563659577384754347）和同一坐标 X-6290、Z3364 再次看到海边一面直立阶梯形沙墙。此前 9462b5b 改善的是**水下海床与岸线的连接**，不会改善截图中明显朝向陆地的沙墙，不能把那次海床测试成功误报为解决视觉问题。

陆地原始地高约Y60，Ocean的水面Y63。旧 `oceanBackshoreMinimum()` 在离海1..2格直接把干岸抬到Y63、3格处最低Y62、4格处最低Y61，但从第5格便恢复Y60（或更低）。这满足挡水要求，却制造宽仅4格、高度差3格的连续人工沙堤。之前 `gentleBankCap` 只处理**原地面在海面之上**的过高岸，当前 `deltaToWater=-3`，完全不满足触发条件。

## 本次独立修复

仅修改 Ocean 的干陆岸最低高度政策：如原始干地低于海水边界1..4格，将必须挡住水的首1..2格保留原高度，余下3..10格按 smoothstep 由水位徐徐过渡回原地面；距离大于10格完全不改原地面。压缩坡度而不是改动水面。超过4格的大低地和天然陡壁保留原安全策略，避免把山崖通通压平；3..10格内部抬高最多3格，保留此前的局部抬高安全限制。Lake/River/湿地等水体归属和水面不修改，海床上轮的1..4格过渡也保留。

这一修改不会新增生物、实体、方块、群系或原版之外的其他玩法。
