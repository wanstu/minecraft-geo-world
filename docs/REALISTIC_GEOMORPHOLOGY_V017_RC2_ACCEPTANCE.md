# GeoWorld v0.1.7-rc.2 候选包验收

2026-11-19 采用提交 `b6a9a12f8b8ac82aad37c68caa53341c2a79bb8f` 构建 9 个目标，均通过 `clean check build`。9 个 JAR 均通过 Loader 元数据、ZIP CRC 与六套原生引擎的架构校验。

Go 全量测试和 Java 7 组、共 126 个 golden 样点通过。RC.1 与当前 Java Reader 对 v1.1.25、v1.1.26 和 v1.1.27 存档各比较 928 条完整 Runtime 记录，结果一致。Web 地图与 Java Runtime 的 21 个坐标通过对照。v0.1.6 的 5 个几何对照点保有相同的整格高度、水位和水体归属。

## 新世界体素

在 26.3 Fabric 直接启动候选 JAR，在 1.21.1 NeoForge 复查同一固定种子 `-1818694639628404530` 的 v1.1.28 新世界。地形验收关闭原版结构生成。两端模型的 SHA-256 相同，953 条河段、471 个湖节点及 18 处特殊地貌的持久化数据与 RC.1 一致。新读取 38 个 Fabric FULL 区块，NeoForge 累计 231 个。

| 复测 | 实际结果 |
| --- | --- |
| #509 河口 | `(-1088, -1088)` 到 `(-1188, -1088)` 的 101 列河床和水面逐格相同，水深 5 格，水面 Y=62 |
| #43 河口 | 比较线 64 列的河床和水面逐格相同，最浅 3 格，Fabric 河口影响区有 0 个珊瑚方块 |
| 内陆河湖接缝 | 两端都在 `(1480, -4664)` 附近对齐到 Y=64，在 `(2715, -7957)` 附近对齐到 Y=88 |
| 珊瑚礁正对照 | Fabric 在 `(-2064, -2016)` 附近生成 1,428 个珊瑚方块 |

26.x 的 3D 群系指纹对比每颗种子有 24,576 次采样。两个种子各有 3 个海洋列达到珊瑚适生水深，每列在 4 个高度的群系由 `minecraft:lukewarm_ocean` 变为 `minecraft:warm_ocean`。验收指纹随 v1.1.28 锁定。
