## 自动验收

- Go 全量测试通过，Go ↔ Java 的 7 组 golden 共 126 个样点通过。Save → Load 特殊地貌计划验收包含在 Go 全量测试中。
- NeoForge 1.21.1 保存世界中，本轮 46 个目标区块全部达到 FULL。
- 14 个固定坐标的 Web 样本与 Java Runtime 一致，底层 Minecraft 地面均与标注高度一致。验收覆盖 5 个 geomV8 复测点、原天坑冲突区、4 个雪地貌及珊瑚对照区。
- #509、#915 及热带河口 #43 使用同一模型哈希的 [Slice F Anvil 证据](acceptance/v017_r82_biome_distribution_v127_voxel.json)。#43 航道核心最浅 3 格，河口影响区珊瑚为 0。
- 9 个目标均通过 `clean check build`。9 个 JAR 均通过 ZIP 完整性、Loader 元数据与六个平台原生引擎架构校验。
- 26.x 群系指纹锁定 v1.1.27 的结果，26.3 Fabric 地貌测试使用自然生成三种岛的小地图种子。各目标的构建提交随矩阵记录，后续改动均位于验证代码。
- v1.1.25 与 v1.1.26 的持久化模型分别在 `afd7499` 和候选版本的 Java Reader 中各复验 74 个样点，Runtime 结果逐字相同，文件 SHA 一致。

## 全图河流审计

模型报告的 6 次逆升和 27 处相邻水面高差，在保存的 NeoForge 区块中分别复现 5 次和 23 处。实际高差包含两处顺流下降的陡坡急流。平缓航道内的湖水归属冲突在两处各复现 5 对相邻方块。

| 区域 | 相邻列 | Anvil 水面 |
| --- | --- | --- |
| #929 附近 | `(1480, -4664)` 与 `(1481, -4664)` | 湖水 Y64、河水 Y61 |
| #152 附近 | `(2715, -7957)` 与 `(2715, -7956)` | 湖水 Y88、河水 Y86 |

同位置的模型异常已存在于 v1.1.25 和 v1.1.26。两处湖水会提前覆盖正式河道，形成可能阻碍上行的跳变。其余实测逆升为 1 格。发布前需处理这些内陆航道问题，人工控船与地貌观感也需在 eadm 验收。
