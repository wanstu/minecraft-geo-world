# GeoWorld v0.1.1

## 中文

### 修复与改进
- 修复盆地与河流交会处的地上河：以共同水面为基准下沉河道，保留水面以下的河床深度。
- 同步 Go 世界模型与 Java 区块生成，增加干岸、河道水深与方块边界回归检查。
- 改进 WebUI 按需计算与进程管理；Windows 原生程序使用 GeoWorld 缓存目录，避免全局临时目录中的启动失败。
- 修正 Minecraft 26.3 资源标识类型兼容，整理共享客户端与版本适配。
- 汇入特殊地形、矿区、聚落、航运、交通、区域优势分析，以及地图与结构查询工具的近期开发。

### 安装与存档
请选择与 Minecraft 版本、加载器完全一致的 JAR，每次只安装一个 GeoWorld JAR。
新世界使用 `geoworld-rules-v1.1.16`。已有世界继续使用创建时锁定的规则，升级 JAR 不会重新生成旧区块。测试盆地修复时，请使用相同 Seed 新建世界。

发布文件全部由 GitHub Actions 从标签提交构建，附带 `SHA256SUMS.txt`。

## English

### Fixes and improvements
- Fix raised rivers crossing basins. Lower the shared water datum and translate the riverbed by the same amount, preserving channel depth beneath the basin floor.
- Keep the Go model and Java chunk generation consistent, with regression checks for dry banks, water depth, and final voxel boundaries.
- Improve on-demand WebUI analysis and process management. Extract the Windows native WebUI executable into GeoWorld's own cache directory.
- Update shared client integration and Minecraft 26.3 resource identifier compatibility.
- Include recent special-landscape, mining, settlement, navigation, transport, regional analysis, and map/structure tools.

### Installation and existing worlds
Use exactly one JAR matching both your Minecraft version and loader.
New worlds use `geoworld-rules-v1.1.16`. Existing worlds retain their locked generation rules; updating the JAR does not regenerate existing chunks. Create a new world with the same seed to verify the basin correction.

All release files are built by GitHub Actions from the tagged commit. Checksums are provided in `SHA256SUMS.txt`.
