# GeoWorld v0.1.7

本版改善河流航运、河口海底衔接、森林与珊瑚分布，以及特殊地貌选址。

## 河流与海岸

- 河道可航核心至少有 3 个实际水方块，河岸保持渐浅过渡。
- 加深河口外海大片仅一两格水深的浅滩，改善河道进入外海的连续性。
- 正式河口沿用统一海平面，河口航运影响区使用适合通航的海洋群系。
- 修正内陆河湖交界处的水面跳变，使河流与接收湖泊共享连通水位。

## 群系与特殊地貌

- 收窄过于宽泛的森林覆盖，调整森林、疏林和开阔地的分布。
- 将暖海水温与珊瑚礁适生区分别判断，珊瑚礁结合水温、深度、开放海程度和河流影响生成。
- 雪火山坑与雪盆地增加山地背景、温度、高程、起伏和内陆连续性条件。
- 海岛类特殊地貌增加水下基底条件，改善岛体与周围海床的连接。
- 天坑选址增加正式河道冲突检查。

## 界面

- 修复 Minecraft 1.21.1 创建世界设置页的点击穿透，滚动区外的控件正确让出「完成」「取消」按钮的点击。

## 安装与存档

按 Minecraft 版本和加载器选择对应 JAR。

| Minecraft | 加载器 |
| --- | --- |
| 26.3、26.2、26.1.2、1.21.1 | Fabric、NeoForge |
| 1.20.1 | Fabric |

新建 GeoWorld 世界使用 `geoworld-rules-v1.1.28`。已有世界继续依据存档中的生成规则读取。体验新版地形与水文时使用新世界。

正式包由 GitHub Actions 从 `v0.1.7` 标签构建，包含 Windows、Linux、macOS 的 x64 与 arm64 原生引擎。Release 附有九个 JAR 和 `SHA256SUMS.txt`。
