# GeoWorld v0.1.2

状态：标签 CI 未通过，未发布。26.1.2 / 26.2 的旧指纹基线修正后改用 v0.1.3；保留本标签与记录。

## 中文

### 修复与改进

- 开放已验收的 Query API v1：通过 `GeoWorldFacade / WorldFacts` 读取当前服务端动态主世界的自然事实，登记并验证全部 86 个字段，明确版本与缺失值契约。
- 世界关闭、加载失败和切换时正确解除查询绑定；保留旧视图不会把旧世界重新设为当前世界。查询只读取锁定模型，不触发区块加载或生成。
- 修复 Java Runtime 对稀有地形强度、孤峰、断崖和大型河谷的读取/计算偏差，使采样与持久化模型一致。
- 修复直接创建世界时未发现模组矿物的问题，在新模型生成前扫描注册表；已持久化模型保留冻结配置。
- WebUI 根据玩家维度暂停或恢复主世界联动，跨维度时隐藏主世界位置标记并限制坐标操作。
- 修复 1.21.1 要塞定位入口，按 Minecraft 版本使用对应群系规则；结构名称使用常用中文。

### 验证范围

- Go 全仓测试、6 个模型的 108 个 Java/Go golden 样点，以及全部 QUERY-01～10 通过。
- 1.21.1 NeoForge 与 26.3 Fabric 完整检查及实际进入 A → 返回标题 → 进入 B 通过。
- 发布矩阵为 9 个 Minecraft / Loader 目标，正式 JAR 均由 GitHub Actions 构建和检查，并附带 `SHA256SUMS.txt`。
- Query 矿业评分仍使用 8 类原版矿物家族；模组矿物生成与查询评分的覆盖范围不同。矿堆显示、跨维度交互及其他试玩项目的剩余验收见仓库 STATUS。

### 安装与存档

请选择与 Minecraft 版本、加载器完全一致的一个 JAR。新世界继续使用 `geoworld-rules-v1.1.16`；已有世界保留锁定模型和规则，更新不会重新生成已有区块。Query 契约仍为 `geoworld-query-v1`，模型格式未改变。

调用说明：[Query API](../../java/runtime-reader/README.md#query-api)。字段契约：[FACT_REGISTRY](../FACT_REGISTRY.md)。

## English

### Fixes and improvements

- Open the accepted Query API v1 through `GeoWorldFacade / WorldFacts`, with documented and verified contracts for all 86 natural fields.
- Bind facts only to the logical server's dynamic GeoWorld Overworld. Clear bindings on shutdown, failed activation and world replacement; model queries never load or generate chunks.
- Align Java sampling of rare terrain strength, isolated peaks, rare cliffs and large valleys with persisted models.
- Discover registered modded minerals before generating a new world model, including when the preset editor is skipped. Existing models retain their frozen configuration.
- Suspend Overworld WebUI tracking and coordinate actions outside the Overworld, then resume on return.
- Fix the Minecraft 1.21.1 stronghold lookup entry point and use version-specific biome rules; improve Chinese structure names.

### Verification and compatibility

Go tests, 108 cross-language golden samples across six models, and QUERY-01 through QUERY-10 passed. Full checks and live world-switch tests passed on Minecraft 1.21.1 NeoForge and 26.3 Fabric. All nine release targets are built and checked by GitHub Actions; checksums are included.

Use exactly one JAR matching your Minecraft version and loader. New worlds retain `geoworld-rules-v1.1.16`; existing worlds keep their locked model and rules. Existing chunks are not regenerated. The Query contract remains `geoworld-query-v1` and the world model format is unchanged.

Query mining scores currently cover eight vanilla mineral families; runtime generation may include modded minerals. See the repository status document for remaining gameplay-facing manual checks.
