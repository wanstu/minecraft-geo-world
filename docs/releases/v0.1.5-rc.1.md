# GeoWorld v0.1.5-rc.1 — 真实地貌强化测试版

2026-11-10 · 预发布（供玩家测试，不标记正式稳定版）

## 中文

### 本次游戏内改变

- **盆地河流出口修复（R2）**：修复樱花/雪地特殊盆地径向挖掘导致河流从盆底流向出口时逆坡爬升的问题；同时校验河面、河床、河岸和盆地出口几何，不重新引入早已撤回的 receiver v1.1.17 方案。
- **成熟冲积河纵剖面（R2）**：只针对满足地貌、坡降、侵蚀沉积条件的低地冲积河段，在 Geomorph → Terrain 的已有流程中应用坡降修正；山地、峡谷、构造河流仍可保留自然陡坡。
- **沿河网输沙与沉积反馈（R4）**：沿 FlowTo 网络累计侵蚀产沙，受搬运能力/沉积空间限制，并将沉积反馈到 Terrain；以收支守恒为约束。生成规则版本提升至 `geoworld-rules-v1.1.20`。
- **过渡回归（R5）**：山地—平原、盆地边缘—盆底、河谷—洪泛平原、陆地—海岸—海底四类连续性验收已添加，不通过全局模糊、强行插入地貌类型或者让所有海岸统一成缓坡来追求指标。

### 开发期对照（不会进入游戏的文件/运行时依赖）

- R6 建立 NASADEM、HydroSHEDS、JRC Surface Water、HydroRIVERS 与 GEBCO 的参考数据规范；目前仅 **REF-04 赞比西河**已有候选水文空间统计区间。
- 新增 Go 离线 GeoTIFF/水文处理命令和候选参考 JSON。**未完成 7 个参考区的真实地貌对照，不宣称 GeoWorld 通过了真实世界统计的全面验收**。
- R6 数据尚未用于自动调参，Minecraft JAR **不需要原始 NASADEM/JRC/HydroSHEDS/GIS 文件**。

### 如何测试（推荐 1.21.1 NeoForge）

1. 保留旧存档备份，安装与游戏版本和加载器匹配的 **GeoWorld-0.1.5-rc.1** JAR。不要同时保留旧版 GeoWorld JAR。
2. 新建世界使用种子 `123456`（创造模式便于观察），保持 GeoWorld 生成设置默认值。新世界应锁定 **`geoworld-rules-v1.1.20`**。
3. 观察山地入平原过渡、河流是否穿过盆地低处并顺坡出谷、河岸有无悬空/突变、高原峡谷是否仍保持陡峭、冲积扇和河漫滩是否有明显规整图案。
4. 验证河流入海、湖泊出口、河流汇合是否存在违和；海岸同时观察缓坡海岸和陡峭海岸，不要求所有海岸地貌一样。
5. 可继续验证以前已实现的矿区、原矿堆、WebUI 等功能，确保未引入回归。
6. **旧存档只用于兼容性验证，不适合与新规则生成的固定 Seed 世界直接做地貌对照**。不要期待已生成区块重新塑形。

另可抽查种子：`-4852173505788415804`、`-563659577384754347`、`4034658472718554561`。

### 兼容性和界限

- 新旧 world model / 生成规则仍按既有锁定机制选择，不对已有世界强制升级。
- 本测试版只针对 **Overworld 世界生成**，不扩展玩法系统、不修改下界/末地生成。
- 预发布版供验收；如果发现世界生成差异或载入问题，以截图、Seed、游戏版本及加载器为复现依据。

## English

### In-game changes

- Fixed river profiles crossing special cherry/snow basin outlet corridors while keeping river surfaces, beds and banks coherent.
- Added selective downstream grade correction for mature alluvial lowland rivers; steep mountain and canyon rivers remain steep.
- Routed erosion-derived sediment along the existing flow graph and applied bounded, mass-conserving deposition feedback to terrain. New worlds use `geoworld-rules-v1.1.20`.
- Expanded read-only audits for mountain/plain, basin rim/floor, river valley/floodplain and coastal transitions.

### Offline research (not bundled with the mod)

- Added reference data registry and offline DEM/hydrology extraction and spatial-envelope tools.
- Real-world reference envelopes currently cover hydrological candidates for REF-04 only; **full seven-region validation is not complete**. These values do not automatically retune world generation.

### Testing

Use a matching JAR for your Minecraft version and loader, remove the previous GeoWorld JAR and create a new world with seed `123456`. Check river outlets through basins, downstream gradients, riverbanks, depositional lowlands, varied coastline shapes and existing features. Back up existing saves; already generated chunks are not reworked. Other deterministic review seeds: `-4852173505788415804`, `-563659577384754347`, `4034658472718554561`.

Minecraft JARs contain no real-world raster datasets or GIS runtime requirements.
