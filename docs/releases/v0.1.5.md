# GeoWorld v0.1.5 — 正式版发布说明草案（未发布）

> 注意：本文件是发布准备，不代表已创建 v0.1.5 标签或上传 JAR。正式发版必须使用 GitHub CI 对当前 master 的 tag 构建和发布。

## 本版相对 v0.1.4 的主要更新

- **地貌与水文**：保留 R2 的特殊盆地河流排水走廊修复、成熟冲积河纵剖面处理和沿流向网络的侵蚀、搬运、沉积反馈。河道及周边地表的生成仍遵守世界模型的一致性约束。
- **R7 宽河流自然化**：只有符合宽度、长度、较缓坡降条件的河段才采用有边界的曲率改良；不强行弯曲全部河流。
- **R7 河流源头过渡**：新规则 v1.1.22 对宽河流源头做有限的渐变收窄，Go 和 Java 地形查询保持对等。
- **创建世界**：保留生成世界模型时的明确进度展示和 v0.1.4 已验收的自动创建世界模型、默认地表原矿堆等行为。
- **可靠性**：继续维护旧世界的持久化生成规则、模型格式与运行时查询兼容。WebUI 的 Linux/Windows 看门狗验收现检验实际 HTTP 恢复能力，不依赖不可保证的 TCP 端口立即复用。

## 范围与兼容

- 新创建的 GeoWorld 世界使用 **`geoworld-rules-v1.1.22`**。保留旧世界各自已写入的生成规则，不自动迁移、不重新塑形已生成区块。
- **不包含** v1.1.25–v1.1.31 中实验性的天坑修改及其他尚未通过真实游戏视觉验收的地形候选。
- 目前还没有完成所有卫星/DEM 参考区和所有地貌的现实对照。**不能将 v0.1.5 宣传为“真实地貌全面通过验收”**。
- 仅影响 GeoWorld 主世界生成和现有只读 WebUI 相关功能；不增加玩法或修改下界/末地生成逻辑。

## 测试与安装

- 支持九个构建目标：26.3 NeoForge/Fabric、26.2 NeoForge/Fabric、26.1.2 NeoForge/Fabric、1.21.1 NeoForge/Fabric、1.20.1 Fabric。
- Windows 九目标由 GitHub Actions 对候选分支进行 `clean check build`；当前已有的 9/9 PASS 为 PR #3 初始提交，正式标签发布前需取得**最终提交的相同验收**。
- 本地 1.21.1 NeoForge 的旧 v1.1.21 存档可正常加载并仍绑定原规则；新种子 123456 进入原生客户端并可保存退出，生成新规则 v1.1.22。
- 建议玩家备份旧存档，每个 Minecraft 安装只保留一个匹配游戏版本及加载器的 GeoWorld JAR。旧存档不会自动获得新规则生成的地形。
- 可重点检查种子 `-1818694639628404530` 在 X=-3264、Z=-1792 附近的宽河流与头部过渡，以及种子 `123456` 的新世界水文、海岸、矿区、原矿堆和 WebUI。
