# GeoWorld v0.1.5-rc.3 — R7 宽河流自然弯曲测试版

2026-11-10 · 预发布（只用于测试，不代表全部地貌已通过现实对照）。

## 中文

本次只针对 R7 实际存档验收发现的 **宽、缓流、长距离笔直河道** 进行最小定向修复。

- **新规则 `geoworld-rules-v1.1.21`**：原来属于随机直段分支的部分宽河流，若长度至少 96 方块、半宽至少 10 方块且低坡降权重高，获得幅度有上限的弯曲。
- 保留窄河、山地急流、部分自然直段、河口以及湖泊进出水口的原有几何。
- 河网宏观节点与宽度不变，弯曲只影响节点之间的河道中心线；同时继续使用原有河床纵剖面、河岸自由水面限制。
- 核心回归包含 `ttt` 已观测的 Segment #48：旧版偏移为 0，新规则候选偏移约为 10.88 方块；**已创建的 `ttt` 世界不会自动重新生成**。
- 客户端模型缓存格式提升为 `v25`，避免复用上一测试版的生成缓存。
- 此次没有额外添加新玩法、材料或修改下界、末地。

### 建议测试

1. 备份旧存档，安装匹配 MC 版本/Loader 的 rc.3 JAR，并删除同时存在的旧 GeoWorld JAR。
2. 用种子 `-1818694639628404530` 新建同参数 Standard 世界，新世界应锁定 `geoworld-rules-v1.1.21`。
3. 创造模式传送到 `X=-3264, Z=-1792` 附近（西部河段中心），从空中俯视河道是否不再是长直线，注意河岸是否平滑、水面是否连续。
4. 对比 `ttt` 原旧模型在相同位置的截图，但**不要对旧存档强制重建模型**。
5. 使用种子 `123456` 检查河口、湖泊进出口、主河汇合、山地河谷、海岸，以及矿区/WebUI 等旧功能的回归。

### 范围限制

本版本只减轻部分长直段。宏观河段方向变更处的明显折角仍需要独立 R7.2 处理；真实 DEM/卫星参考区间尚未完成所有地区的对照，因此不得宣称“真实世界地貌全面达标”。

开发与验收详情：`docs/REALISTIC_GEOMORPHOLOGY_R7_RIVER_GEOMETRY.md`。

## English

**R7 selective wide-river meander pre-release.**

- New worlds use `geoworld-rules-v1.1.21` / RiverGeometryVersion 6.
- Add bounded lateral curvature only to qualifying long, wide, low-gradient cardinal river reaches from the previous straight-reach subset. Maintain a small natural straight subset.
- Preserve river macro nodes, widths, steep/narrow rivers, mouths, lake connections and old-version world locks.
- Bump model generation cache format to v25. No new gameplay features, external GIS runtime or raw raster data.
- Test seed `-1818694639628404530` near `(-3264,-1792)` in a **new** Standard world. Existing chunks/saves are never automatically reshaped.
- Junction tangent smoothing and complete global real-world DEM validation are not included in this pre-release.
