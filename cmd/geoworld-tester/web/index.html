参数与预设

GeoWorld 预设只是参数集合，所有预设共享同一套世界模型与生成器。

Standard

默认质量基线，平衡大陆、水系、山体、生态与可建设性。

Natural

自然地理影响更强，强调连续地貌、水文与生态因果。

Civilization

保留自然骨架，同时提高可利用平原、交通走廊等文明友好条件。

Epic

放大宏观山系、高原、河谷和区域尺度，保持同一因果模型。

世界版本锁定

创建世界时保存 Seed、完整参数快照、World Profile Version、Generation Rules Version 与 World Model Version。升级 GeoWorld 后，旧世界继续使用创建时锁定的规则。

设计原则
