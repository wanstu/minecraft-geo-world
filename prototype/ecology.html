这一页看什么

这里先决定“长期是什么生态环境”，还没有直接映射成 Minecraft Biome。森林、草原、荒漠、苔原等会先由长期温度、水分、季节性、山地和湿地共同推导。
生态与群系
温度 + 水分 + 季节性 + 地形 → 长期生态
这一步回答“这里长期适合长什么”。 温度决定生长季和寒冷程度，降水与蒸发需求共同决定湿润或干旱；季风控制雨季 / 旱季，山地和河漫滩又会形成高山、湿地等特殊生态。最终 Minecraft Biome 会在下一步基于这些长期生态区继续细分。
绿色系：森林黄绿色：草原 / 稀树草原黄褐色：荒漠 / 灌丛灰白：高山 / 苔原 / 冰原蓝绿色：湿地蓝色：海洋生态
① 长期生态区森林、草原、荒漠、苔原、高山、湿地和海洋
② 水分是否够用同样的降水，在炎热地区会更容易变干
③ 干旱倾向越亮越容易形成草原、灌丛或荒漠
④ 总体植被茂密程度温度与可用水分共同控制
⑤ 树木覆盖倾向长期温暖湿润区域更高
⑥ 草地覆盖倾向中等水分和平缓地形更容易出现
⑦ 灌丛覆盖倾向偏干、季节性明显地区更常见
⑧ 裸地倾向极干、极冷或高山环境会升高
⑨ 积雪 / 冻土倾向受冬季温度、高山和年平均温度影响
⑩ 土壤湿润度长期降水 + 河流 / 湿地补水
⑪ 湿地生态倾向湖沼、河漫滩、宽谷底等共同影响
⑫ 高山生态倾向低温 + 强山地 / 高原背景 + 高起伏

怎么理解

生态区不是天气

一次下雨或一次下雪不会改变群系。这里使用的是长期温度、长期降水和季节性。

荒漠不只看降水量

炎热地区蒸发需求更大，所以同样 500mm 降水，在热带和寒带代表的水分条件并不一样。

高山会覆盖纬度规律

即使位于温暖纬度，只要海拔和起伏足够高，仍可能形成高山草甸、裸岩或积雪生态。

下一步才是 Minecraft Biome

例如同一个“温带森林”生态区，还可以根据丘陵、河漫滩、土壤湿度和局部细节映射成不同 Minecraft 生物群系或表面材料。
