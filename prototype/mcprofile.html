这一页看什么

这里把“长期生态”转换成 Minecraft 需要的生成配置：地形形态、地表材料和植被类型。现在仍是 Core 语义，不绑定 NeoForge / Fabric / Forge，也还没有写死具体方块注册表。
Minecraft 群系与地表
生态 + 地貌 → Minecraft 生成配置
同一个生态区不应该只对应一种 Minecraft Biome。 例如温带森林位于平原、丘陵、河漫滩时，会保留相同的长期生态家族，但地形形态、土壤和植被生成配置可以不同。
① 群系生态家族长期生态语义，不直接绑定某个 Loader 的注册表 ID
② 地形形态平原、丘陵、山麓、山地、高原、河漫滩等
③ 地表材料配置森林土、草土、沙砾、冲积土、湿泥、岩石、雪冰等
④ 植被配置针叶林、混交林、雨林、草原、稀树草原、灌丛、湿地等
⑤ 配置置信度越亮表示生态和地形信号越明确

为什么要再分一层

生态区 ≠ Minecraft Biome

“温带森林”描述长期生态，但 Minecraft 还需要知道这里是平地、丘陵、湿地还是山坡，以及表面铺什么、长什么植物。

Core 不绑定 Loader

这里输出稳定的语义 Profile。以后 NeoForge、Fabric、Forge Adapter 再决定映射成 Vanilla Biome、自定义 GeoWorld Biome 或第三方兼容群系。

特殊河流地貌不会丢

河漫滩、冲积平原、冲积扇和峡谷作为覆盖地貌优先保留，不会再次被普通“平原”权重盖掉。
